## ⑥ BM — 지그 경계조건 기호(방식별, 3D 의 tie·받침점 표시 = BC)
지그 ESL 결과가 있는 Case 의 ③ 3D 에서 출처 탭 **지그 고정 · 지그 변위 · 지그 스프링** 을 차례로 열고(이전에 만든 3D 면 다시 만들기), [경계조건] 층을 켠다. 스터디 3D(지그 방식 비교)도 같은 기호다.

| 방식 | 볼 것 | 기대 | 결과 |
|---|---|---|---|
| 지그 고정 | tie 노드 | 회색 막대 + 바닥 빗금, **법선 방향 1개**(꺾인 노드는 2개) — 세 축 막대 아님. 탐침: "지그 고정 · 방향 법선 (…) · 고정 0" | |
| 지그 변위 | tie 노드 | 청록 화살표(길이 = g × 표시 배율, 방향 = g 부호) + 끝 막대. 변형 배율을 바꾸면 화살표 길이가 같이 바뀜. 탐침: "g … mm" | |
| 지그 스프링 | tie 노드 | **주황 지그재그 스프링 + 받침 막대(법선만)** — 면내 1·2 는 구속 표시 없음. 탐침: "k … N/mm · g … mm"(k 에 값이 나오고 "–" 가 아님) | |
| 세 방식 공통 | 받침점(3-2-1 면내 n₁·n₂) | 보라 양방향 화살표 + 삼각, n₁ 2방향·n₂ 1방향(판 면내) — 법선 방향 화살표 없음 | |
| 범례 | [경계조건] 칩 툴팁 | 그 화면에 있는 기호의 한 줄 뜻(스프링: "주황 스프링 = tie 법선만 스프링(면내 자유) · 받침 = 낙하 변위 g") | |
| 옛 3D | v0.24.8 이전에 만든 지그 3D | 옛 기호 그대로 + 칩 툴팁 "이전 형식 — 다시 만들기를 누르면 방식별 기호로 표시". 전 노드 ESL 3D(3-2-1 지지)에는 이 안내가 없음 | |
| 화면 높이 | 2560·1920 | 이전과 같음(새 줄·새 버튼 없음) | |
