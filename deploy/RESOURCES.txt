ESL 서버 반입 자원 안내(physicsai deploy/RESOURCES.txt 대응)

ESL 서버가 실행하는 외부 프로그램은 HyperView hw(서버 h3d 추출, 계약 esl_p3_ux.md §6) 하나다 — 서버에 HyperWorks 2026.1과
라이선스가 있어야 한다. 설정 altair.hw_exe_path(기본 C:/Program Files/Altair/2026.1/hwdesktop/hw/bin/win64/hw.exe),
altair.max_concurrent_hw(동시 hw 수 — 라이선스 한도), worker.slots·per_job_memory_gb(동시 작업·작업별 메모리).
추출 TCL(resources/tcl/esl_h3d_extract.tcl)은 코드 스냅샷 <런타임>\app\resources\tcl 로 함께 배치된다(따로 복사할 것 없음).
서버 추출 CSV는 <esl_root>\_h3d\<Case 폴더>\raw 에 쓴다.

  계산 코어(esl)            묶음 app\esl (설치 스크립트가 <런타임>\app\esl로 배치)
  솔버 의존성               묶음 wheels — deploy\requirements.lock 고정: pypardiso(+mkl·intel-openmp·tbb, Windows MKL 휠),
                            pyamg, psutil, numpy·scipy. scikit-sparse(CHOLMOD)는 Windows 휠이 없어 제외(solver.backend auto → pardiso)
  코어 설정                 <런타임>\config\esl.yaml (config/esl.example.yaml 복사 — 판정 기준 validation·compare는 사내 확인 후 교체)
  라이브러리 설정           <런타임>\config\library.yaml + ista6.yaml (config/library.example.yaml, config/ista6.yaml 복사 — 낙하 높이 표는 TODO)
  비드 DOE 형상 엔진(v0.9.0) 묶음 wheels — paicad-<ver>-py3-none-any.whl(physicsai-platform packages/paicad, deploy\paicad.lock 의
                            커밋·버전·정규화 sha256 으로 collect-offline 이 빌드·대조) + requirements.lock bead_doe 절(cadquery-ocp·vtk·gmsh).
                            설치 venv 에 <런타임>\venv\Scripts\paicad.exe 가 생기고 setup_config 가 bead_doe.paicad.exe 를 채운다(있을 때만).
                            설치 실패해도 다른 기능은 동작(비드 DOE 만 비활성). gmsh 는 GPL(+예외) — 사내 설치 용도, 묶음 크기 수백 MB 증가.
                            확인: <런타임>\venv\Scripts\paicad.exe version --json (paicad ≥ 0.14.0, ocp 값 있음),
                                  <런타임>\venv\Scripts\python.exe -c "import gmsh; print(gmsh.__version__)"

입력 데이터(rad + 결과 CSV 폴더)는 사용자 PC에서 HyperView TCL로 만든다(저장소 루트 update.bat — 사용자 PC용, 서버 설치와 무관).
서버는 그 폴더를 storage.input_roots 아래에서 읽기만 한다. 설치 후 환경 점검:
  <런타임>\venv\Scripts\python.exe <런타임>\app\esl_service.py check --runtime <런타임>
경로에는 공백·cmd 메타문자(& | < > ^ % ! ")를 쓰지 않는다.
